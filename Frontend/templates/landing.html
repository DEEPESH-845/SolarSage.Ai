How the loop closes

Four steps, then it starts again.

These stages run in order, and each one hands the next a number rather than an opinion. Nothing sprays until the last step has a reason to.

01

Capture

An ESP32 at the array pushes one frame per panel with a sensor sweep beside it — temperature, humidity, irradiance, output.

{{ icon('camera', 14) }} {{ panels.total_panels if panels else 0 }} cameras · {{ (health.camera_status if health else 'offline')|title }}

02

Classify

OpenCV scores dust coverage on the frame and returns a confidence next to it, so a bad photo cannot pass itself off as a clean panel.

{{ icon('scan', 14) }} coverage + confidence, ~{{ analysis.get('processing_time_ms', '—') }} ms

03

Price

Coverage becomes kilowatt-hours: what the dust costs per day, what a wash costs, and how many days it takes to pay that back.

{{ icon('money', 14) }} last run: pays back in {{ analysis.get('payback_period_days', '—') }} days

04

Act

Above {{ config.dust_threshold }}% coverage the valve opens for {{ config.spray_duration }} seconds at {{ config.water_pressure }} pressure. Between {{ config.schedule_threshold }}% and {{ config.dust_threshold }}% it only schedules. Below that, nothing happens.

{{ icon('droplet', 14) }} {{ config.spray_duration * 20 }} ml per cycle
